# Data

Unduh dataset **Blue Book for Bulldozers** dari Kaggle
(https://www.kaggle.com/c/bluebook-for-bulldozers/data) dan letakkan file berikut di folder ini:

| File | Isi | Peran di proyek |
|---|---|---|
| `Train.csv` | 401.125 transaksi lelang 1989–2011, dengan harga | data historis: profiling, golden record, model harga |
| `Valid.csv` | 11.573 transaksi Jan–Apr 2012, tanpa harga | batch data baru yang diintegrasikan ke master |
| `Test.csv` | 12.457 transaksi Mei–Nov 2012, tanpa harga | batch data baru yang diintegrasikan ke master |
